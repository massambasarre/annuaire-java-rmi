# Annuaire distribué Java RMI

Consultation et gestion de membres par appels de méthodes distantes.

## Technologies

Java, Swing, Java RMI.

## Installation et utilisation

Définir ANNUAIRE_ADMIN_PASSWORD pour le client administrateur. Avec un JDK : `javac -encoding UTF-8 -d build *.java`, puis `java -cp build projetAnnuaire.Serveur` et, dans un autre terminal, `java -cp build projetAnnuaire.AnnuaireGUI`.

## État et limites

Contrôles administrateur pédagogiques ; aucune garantie d’autorisation robuste côté serveur. Ne pas exposer le registre RMI sur Internet.
